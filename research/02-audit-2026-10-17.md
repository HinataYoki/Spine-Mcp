# Denetim — 2026-10-17

Kapsam: spine-runtimes 4.3 örneklerinin tamamı (36 proje: Pro + Essential, 213 animasyon) üzerinde `scripts/sweep.mjs` + Opus ile bağımsız kod incelemesi. Her proje bir kopyada çalıştı; orijinallere dokunulmadı.

Sweep adımları (proje başına): JSON export → inspect → validate (static + runtime) → her animasyon için measure + timing → derive değişmezleri → gerçek yazma (ease + scale türevi) + doğrulama + yedekten geri yükleme (byte eşitliği) → PNG render.

Derive değişmezleri:
- `retime 1` + `scaleValues 1` = orijinal (spine-core timeline karşılaştırması)
- `retime 2` → `retime 0.5` = orijinal (eğri değerleri tam değerlendirme ile, < 1e-6)
- `offsetBones +0.37D` → `−0.37D` = orijinal (< 0.5; seam atlamalı loop'larda 1 ms pencere hariç)
